# Данные и соединения

У AlbionCraft нет собственного сервера аналитики и регистрации пользователей.
Локально сохраняются настройки, профиль, заказы, запасы, журнал,
планы ходок, кэш котировок и полученные рыночные наблюдения.

Europe использует прежнюю папку данных. Americas и Asia хранятся в её подпапках
`servers/west` и `servers/east`. Общие настройки языка и выбранного сервера находятся
в `app_preferences.json`; изображения предметов общие. Локальный приёмник сверяет
идентификатор сервера перед записью цен и собственных заказов.

Расчётные процессы получают локальный снимок выбранных данных во временной папке.
После завершения или отмены временные файлы удаляются; эти процессы не публикуют данные.

Сетевые соединения:

- REST API Albion Online Data Project: идентификаторы предметов, города и качества.
- Необязательный публичный поток NATS: наблюдения рынка из AODP.
- `render.albiononline.com`: изображения запрошенных предметов.
- Источники билдов: запросы при загрузке билдов.
- GitHub и npcap.com: загрузка клиента/установщика при действии пользователя.
- Локальный HTTP-приёмник `127.0.0.1:43871`: наблюдения и собственные заказы от клиента.

Поставляемая модификация клиента передаёт данные только на loopback-адрес,
не выполняет игровые запросы и не обновляется самостоятельно. При выборе
другого клиента проверяй его настройки и условия передачи данных.

Для банка используется выбранная область видимого экрана. Распознавание
выполняется на компьютере; снимки не отправляются на сервер OCR. Проверяй результат
при неоднозначных иконках, зачарованиях, цифрах или перекрытии страниц.

Перед обращением за помощью убери имена персонажей, пути с именем пользователя,
токены и детали заказов, которые не нужны для воспроизведения ошибки.
Не прикладывай базы и настройки целиком.

Папка данных открывается через меню «Помощь». Для резервной копии закрой программу
и скопируй папку целиком. Не размещай копию в публичном репозитории.
