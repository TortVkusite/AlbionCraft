# Данные и соединения

У AlbionCraft нет собственного сервера аналитики и регистрации пользователей.
Локально сохраняются настройки, профиль, заказы, запасы, журнал,
планы ходок, кэш котировок и полученные рыночные наблюдения.

Europe использует прежнюю папку данных. Americas и Asia хранятся в её подпапках
`servers/west` и `servers/east`. Общие настройки языка и выбранного сервера находятся
в `app_preferences.json`; изображения предметов общие. Локальный приёмник сверяет
идентификатор сервера перед записью цен и собственных заказов.

Расчётные процессы получают локальный снимок выбранных данных во временной папке.
После завершения или отмены временные файлы удаляются; эти процессы не публикуют данные.

Сетевые соединения:

- REST API Albion Online Data Project: идентификаторы предметов, города и качества.
- Необязательный публичный поток NATS: наблюдения рынка из AODP.
- `render.albiononline.com`: изображения запрошенных предметов.
- Источники билдов: запросы при загрузке билдов.
- GitHub и npcap.com: загрузка клиента/установщика при действии пользователя.
- Локальный HTTP-приёмник `127.0.0.1:43871`: наблюдения и собственные заказы от клиента.

Поставляемая модификация клиента передаёт данные только на loopback-адрес,
не выполняет игровые запросы и не обновляется самостоятельно. При выборе
другого клиента проверяй его настройки и условия передачи данных.

Для банка используется выбранная область видимого экрана. Распознавание
выполняется на компьютере; снимки не отправляются на сервер OCR. Проверяй результат
при неоднозначных иконках, зачарованиях, цифрах или перекрытии страниц.

Перед обращением за помощью убери имена персонажей, пути с именем пользователя,
токены и детали заказов, которые не нужны для воспроизведения ошибки.
Не прикладывай базы и настройки целиком.

Папка данных открывается через меню «Помощь». «Резервная копия и диагностика»
создаёт приватный ZIP всех трёх серверов. Он включает настройки и локальные базы;
не размещай его в публичном репозитории. Восстановление сохраняет прежний профиль
в `before-restore.zip` и не включает фоновые функции без текущего согласия.

Диагностический JSON содержит только версии, состояние баз и количество записей
из известных таблиц, без имён персонажей, токенов, заказов, путей и сырых логов.
Он сохраняется по выбранному пути и не отправляется автоматически.

История цен и подтверждённые бонусы хранятся локально. Скриншот бонусов читается
из буфера обмена по действию пользователя; OCR использует встроенную модель.
Автозапуск и автоподключение клиента включаются только в настройках. Приложение
по умолчанию не передаёт локальную историю другим пользователям. Публичный поток AODP и REST
остаются отдельными соединениями: приостановка локального клиента останавливает
его захват, а не обновления из публичных источников.

Обмен с друзьями включается отдельно в «Помощь → Обмен данными с друзьями».
Он передаёт участникам закрытой группы только наблюдавшиеся рыночные страницы
(предмет, город, сервер, качество, сторона, цены, количества, ID и сроки ордеров)
и агрегированную историю торгов. Данные банка, личных заказов, персонажа, токены
локального клиента и снимки экрана в протокол не входят. Полученные записи могут
пересылаться другим участникам группы с исходным автором и временем наблюдения.

Соединения Iroh шифруются между участниками. Для обнаружения и обхода NAT могут
использоваться публичные службы Iroh; если прямая связь невозможна, зашифрованный
трафик идёт через ретранслятор. Прямые участники видят сетевые адреса друг друга;
оператор вспомогательных служб может видеть метаданные соединений. Бесплатная
инфраструктура имеет ограничения и не гарантирует доступность.

Приглашение содержит секрет доступа к группе. Храни его как пароль. На Windows
ключ узла и секрет группы защищены DPAPI текущего пользователя; журнал обмена
хранится в `peer-sync.sqlite`, отдельно от собственных наблюдений. Он не входит
в резервные копии и диагностические отчёты приложения. Блокировка участника
запрещает прямое соединение на этом устройстве; она не удаляет уже переданные
копии и не отзывает приглашение у всей группы. Для смены состава недоверенной
группы следует создать новую группу с новым приглашением.
