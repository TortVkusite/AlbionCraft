# Cyrillic OCR model

`cyrillic_PP-OCRv5_rec_mobile.onnx` is the PaddleOCR Cyrillic recognition model
distributed by RapidAI/RapidOCR 3.9.2. It is used locally for event screenshots;
images and recognized text are not sent to a service.

Source: https://www.modelscope.cn/models/RapidAI/RapidOCR/resolve/v3.9.2/onnx/PP-OCRv5/rec/cyrillic_PP-OCRv5_rec_mobile.onnx
