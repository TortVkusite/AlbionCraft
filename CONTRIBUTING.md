# Участие в проекте

Для ошибки укажи версию AlbionCraft, Windows, действия перед ошибкой и ожидаемый
результат. Для ошибки формулы добавь обезличенные входные значения и свой расчёт.
Не загружай реальные настройки, базы, полный сетевой захват или токены.

Установка и сборка: [docs/BUILDING.md](docs/BUILDING.md).
Изменения расчётов должны сохранять различие неизвестных и нулевых значений,
не записывать опыт/запасы до подтверждения фактической операции и не читать
личный профиль в тестах. Используйте временные SQLite-базы.
Формулы подтверждайте источниками, примерами и тестами граничных случаев.

Перед Pull Request выполните `python -m unittest discover -s tests -v`.
Для изменений упаковки выполните проверку собранного EXE. В описании PR укажите
проблему, новое поведение и результат проверки. Вклад в собственный код проекта
распространяется на условиях MIT; права и лицензии сторонних компонентов сохраняются.
