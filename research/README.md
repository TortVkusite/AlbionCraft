# Данные игры

Снимок рецептов, названий и прогрессии, используемый калькулятором:
`items.json`, `names.json`, `achievements.json`, `full_gamedata.json`.

Источник: [ao-data/ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps).
Подробнее о формулах и версиях снимков: [DATA_SOURCES.md](../DATA_SOURCES.md)
и `app/config/game_rules.json`. Содержимое игровых данных не становится MIT
из-за лицензии кода AlbionCraft; права на Albion Online принадлежат
соответствующим правообладателям.
