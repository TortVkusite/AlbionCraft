# Какие данные теперь заполняются автоматически

## Реальные котировки

AODP `/api/v2/stats/prices`: стоимость ресурсов и готового предмета, отдельные timestamps sell и buy. Europe использует `europe.albion-online-data.com`, Americas — `west.albion-online-data.com`, Asia — `east.albion-online-data.com`. Кэши разделены по серверу. SQLite сохраняет последнюю ненулевую допустимую котировку. Нулевой ответ не становится бесплатным ресурсом. Если ни API, ни кэш не содержат цену, она остаётся отсутствующей. Перенос цен между серверами, городами, качествами и уровнями зачарования запрещён.

История `/api/v2/stats/history` используется для оценки продаж. API не гарантирует полноту; отсутствие истории не означает отсутствие покупателей. Никакой новый сервис не заявлен как источник выдуманных недостающих цен.

## Игровые бонусы

Загружены фактические `craftingmodifiers.json` и `formatted/world.json` из https://github.com/ao-data/ao-bin-dumps . Они дают производственные бонусы и связь городов с clusterid. Из этих файлов сгенерирован app/config/game_rules.json, сохранён SHA256 исходной выгрузки. Снимок от 02.10.2026.

RRR = bonus/(1+bonus). Focus добавляет 0.59 к production bonus, а не к RRR. Источник формулы: https://wiki.albiononline.com/wiki/Resource_return_rate . Дневной бонус не включён и явно отмечен. Royal City base production bonus 0.18; соответствующий типу предмета городской бонус берётся из dump. Например, мечи Lymhurst получают production bonus 0.33: RRR ≈24.812%, с Focus ≈47.917%. 36.7% — другой сценарий (refining), не значение для крафта меча.

Ручные профили имеют приоритет. Авто-правила включены по умолчанию, но отключаются галочкой. Бонусы станций на островах и hideouts в этот профиль не входят.

Brecilien: рынок clusterid 5003, бонусы из clusterid 5000. В сохранённом игровом
справочнике base production bonus 0.18; сумки, плащи и зелья добавляют 0.15.
Перепродажа в Brecilien включается отдельно: стоимость и доступность маршрута не угадываются.

## Комиссии

В справочном профиле setup=2.5%, sales tax=8% без Premium либо 4% с Premium. Сценарий явно выбирается галочкой «Считать с Premium»; статус аккаунта приложение не определяет. Пользовательские комиссии сохраняют приоритет. Это версионируемый справочник, а не данные рыночного API, поэтому в расчёте остаётся отметка о необходимости сверить текущие комиссии в игре.

Ссылки: https://wiki.albiononline.com/wiki/Marketplace ; https://forum.albiononline.com/index.php/Thread/201146-Setup-fee-not-included-in-Total-price-during-Sell-Order/ ; https://forum.albiononline.com/index.php/Thread/169022-Testserver-Patch-Notes-Into-the-Fray-Patch-6/ . Прямое открытие Marketplace wiki при исследовании вернуло 403; справочные ставки нельзя считать автоматически подтверждёнными текущим сервером. Значения вынесены в config и доступны для ручной корректировки.

## Станция

Питание обычного equipment-рецепта вычисляется из Item Value ресурсов публичного dump: sum(item_value × amount) × nutrition_factor. Для альтернативных рецептов одного результата используется значение его основного рецепта, чтобы замена артефакта на токен не меняла Item Value готового предмета. Если значения ресурсов отсутствуют, питание не угадывается. Коэффициент 0.1125 находится в конфигурации.

Стоимость станции = nutrition × tariff / 100. Источник: https://forum.albiononline.com/index.php/Thread/167434-Explaining-Crafting-Tax-and-more/ . Тариф задаёт владелец; проверенный публичный источник текущего тарифа каждой станции не найден. Вводится только число серебра за 100 питания для выбранного города (или общий сценарий тарифа для всех городов). Программа затем пересчитывает все рецепты. Ручная стоимость станции в профиле имеет приоритет.

При неизвестном тарифе показываются прибыль и ROI с «≤»: это верхние границы ДО станции и прочих неизвестных расходов, а не фактическая чистая прибыль. Известный начальный капитал обозначается «≥». Положительная верхняя граница не получает зелёный или синий цвет. Если даже обе верхние границы ниже −5%, красный фон допустим для такого сценария. В подробностях показываются предельные расходы станции и соответствующий тариф окупаемости; прочие неизвестные расходы уменьшают предел.

## Таблица

Стоимость полной закупки ресурсов показывается независимо от наличия тарифа. Если известна лишь часть ресурсов, сумму нельзя выдавать за полную себестоимость. Строки без полного набора цен по умолчанию скрывает «Только с ценами»; счётчик показывает сколько скрыто, галочка позволяет вернуть их с точными причинами. «Все города» сравнивает независимые операции в каждом городе.

Проверки: 47 тестов; автоматический расчёт палаша на живых ценах без ручного профиля, сохранение границ неизвестных расходов, фильтр цен и отображение подробностей. Статические справочники бонусов нужно обновлять при изменениях игры.
