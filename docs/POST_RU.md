# Текст для публикации

Сделал AlbionCraft — бесплатный помощник для рынка Albion Online Europe.

Можно сравнивать крафт и перепродажу, подбирать прибыльную ходку под вес, бюджет
и фокус, учитывать ресурсы на базе и уже купленные партии. Есть собственные
заказы, билды, древо прогресса, сохранённые сценарии и сверка плана с фактом.

Приложение использует публичные данные и при желании наблюдения из твоей игры.
Само в игре ничего не нажимает. Объёмы и цены могут быть неполными,
поэтому расчёт — подсказка для проверки, а не обещание прибыли.

Windows x64, русский интерфейс. Готовый ZIP работает без Python.
Исходники открыты под MIT. Это первая публичная Beta — буду рад понятным
примерам ошибок и предложениям.
