# Публикация на GitHub

Подготовлены два отдельных архива:

- `AlbionCraft-0.1.0-source.zip` — содержимое репозитория, без личных данных.
- `AlbionCraft-0.1.0-windows-x64.zip` — готовая программа для пользователей.

1. Распакуй исходный архив в **новую папку**. Публикуй именно её: рабочая папка
   старой установки содержит твои настройки, наблюдения, базы и журналы.
2. Создай на GitHub публичный репозиторий `AlbionCraft`, без автоматически
   созданного README и лицензии: они уже находятся в исходниках.
3. Открой терминал в распакованной папке с README и выполни:

```powershell
git init
git add .
git commit -m "Prepare AlbionCraft 0.1.0 public beta"
git branch -M main
```

Затем выполни `git remote add origin` с адресом **своего** репозитория и
`git push -u origin main`. Не используй чужой адрес из примера.

4. В GitHub создай Release с тегом `v0.1.0`, назови его `AlbionCraft 0.1.0 — Beta`.
   Вставь текст из `docs/RELEASE_NOTES.md` и прикрепи Windows ZIP вместе с
   `SHA256SUMS.txt`. Отметь релиз как **pre-release**, пока идут первые внешние проверки.
5. В настройках About добавь описание:
   `Windows-помощник для рынка, переработки, ходок и прогресса в Albion Online Europe.`
   Подходящие темы: `albion-online`, `crafting`, `market`, `python`, `pyside6`, `windows`.
6. Для поста используй `docs/POST_RU.md`, добавь ссылку на репозиторий и Releases.
   В Social preview можно поставить собственный баннер `docs/banner.png`.

Бинарная сборка запускается вручную через GitHub Actions → Windows build.
Workflow создаёт артефакты, но сам не публикует релиз.
После сборки на GitHub проверь артефакт перед размещением.

Обновлять архивы можно скриптом `scripts/package_release.py`: он использует
список разрешённых файлов. Не заменяй его архивацией всей рабочей папки.
