# Первый запуск

1. Распакуй весь Windows ZIP в отдельную папку. Запусти `AlbionCraft.exe`.
2. Выбери город, тип предметов, тиры и зачарования. Нажми «Обновить цены».
3. Проверь возраст цен. «Неизвестно» означает нехватку данных, а «≤» — неучтённые расходы.
4. В «Калькуляторе ходки» выбери города, свободный вес и бюджет. Отметь нужные ресурсы,
   введи тариф станции и доступный фокус. «Учесть открытые тиры профиля» требует заполненного профиля.
5. Подбери план и проверь список закупок, расходы, остатки и объёмы рынка перед покупкой.

В режиме увиденных объёмов приложение знает только полученные страницы рынка.
Режим котировок оценивает закупку по ценам за единицу и не гарантирует наличие всей партии.

## Данные из игры (необязательно)

Открой «Подключить клиент…». Для захвата сетевых сообщений нужен Npcap;
кнопка установки откроет его официальный мастер. Условия Npcap принимаются отдельно.
Не запускай несколько экземпляров клиента. Открой страницы рынка и своих заказов в игре.
AlbionCraft получает локальные наблюдения; точность собственных заказов проверяй по страницам игры.
Просмотр формы создания заказа сам по себе не добавляет заказ — требуется подтверждение сервера.

Без клиента доступны публичные котировки и ручной учёт. Для банка открой его в игре,
выбери контейнер в «Запасах», укажи область полных ячеек и читай соседние страницы с перекрытием.
Подтверждай конец банка только после просмотра последнего участка.

## Где сохраняется профиль

Windows-сборка хранит настройки, заказы, запасы и историю в `%LOCALAPPDATA%\AlbionCraft`.
Папка открывается через «Помощь → Папка моих данных». Перед переносом/резервным копированием
закрой приложение и скопируй папку целиком. Новая сборка использует тот же профиль.

Запуск из исходников сохраняет данные рядом с кодом, как в старых установках.
Для отдельного профиля можно задать переменную `ALBIONCRAFT_DATA_DIR`.

Если программа не запускается, проверь, что ZIP полностью распакован и папка `_internal`
находится рядом с EXE. В отчёте об ошибке укажи версию, Windows, действия перед сбоем и
обезличенную ошибку из журнала. Не выкладывай `settings.json`, базы данных или полный журнал:
они могут содержать имена персонажей, заказы и локальный токен.

Подробно: [USER_GUIDE.md](../USER_GUIDE.md).
